#  Student Performance & Sales Analytics Using NumPy

##  About the Project

This project demonstrates the use of Python and NumPy to perform numerical operations and basic data analysis.

It combines student academic performance analysis with business sales analysis using NumPy arrays, mathematical operations and statistical functions.

##  Project Objectives

- Understand NumPy arrays and their dimensions.
- Perform array creation, indexing and slicing.
- Apply mathematical and statistical operations.
- Analyse student marks and business sales.
- Practise array reshaping and manipulation.

##  Features

### 1. Student Performance Analysis
- Created 2D NumPy arrays to store student marks.
- Calculated student-wise total and average marks.
- Identified the class topper.
- Calculated subject-wise totals and averages.
- Identified the best-performing subject.
- Found the highest and lowest marks.

### 2. Array Creation and Manipulation
- Created 0-D, 1-D, 2-D and 3-D arrays.
- Checked array properties using `ndim`, `shape`, `size` and `dtype`.
- Performed indexing and slicing.
- Reshaped arrays using `reshape()`.
- Flattened and manipulated arrays.

### 3. Sales Analysis
- Created 3D NumPy arrays for sales data.
- Calculated total and average sales.
- Performed branch-wise sales analysis.
- Performed month-wise sales analysis.
- Identified the best-performing branch.
- Identified the highest-selling product.
- Found the highest and lowest individual sales.

### 4. Additional NumPy Operations
- Used `np.where()` for conditional selection.
- Used `np.all()` and `np.any()` for condition checking.
- Performed row-wise and column-wise calculations using `axis`.
- Applied functions such as `sum()`, `mean()`, `max()` and `min()`.

## How to Run the Project

1. Install Python on your computer.
2. Install NumPy using:

```bash

```

3. Open the project in Visual Studio Code.
4. Run the Python file:

```bash
python numpy1_basics.py
```
