# Student Performance & Sales Analytics Using NumPy

## 📌 About the Project

This project was developed as part of my internship to practise Python NumPy concepts and apply them to basic data analysis.

The project analyses student academic performance and business sales data using NumPy arrays and mathematical operations.

## 🎯 Project Objectives

- Understand NumPy arrays and their dimensions.
- Perform array operations and calculations.
- Analyse student marks and sales data.
- Practise indexing, slicing and reshaping.

## ✨ Features

### 1. Student Performance Analysis
- Created student marks using 2-D NumPy arrays.
- Calculated student-wise total and average marks.
- Calculated subject-wise total and average marks.
- Identified class toppers.
- Identified the best-performing subject.
- Implemented student and subject selection using `np.where()`.

### 2. Sales Analysis
- Created 3-D sales arrays.
- Analysed branch-wise sales.
- Compared month-wise and product-wise sales.
- Identified highest and lowest sales.

### 3. NumPy Concepts Practised
- 0-D, 1-D, 2-D and 3-D arrays.
- Array properties: `ndim`, `shape`, `size` and `dtype`.
- Array indexing and slicing.
- Array reshaping using `reshape()`.
- Axis operations using `axis=0` and `axis=1`.
- Mathematical functions: `sum()`, `mean()`, `max()` and `min()`.
- Logical functions: `np.all()` and `np.any()`.
